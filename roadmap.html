Ukurra · Jalur Produksi

Dari kondisi sekarang, sampai bisa dipakai pengguna sungguhan.

Murni jalur teknis: hosting, akun, pembayaran, dan distribusi. Tidak ada pendaftaran merek, HKI, atau izin usaha — itu bisa menyusul kapan saja dan tidak menghalangi produk berjalan. Paket lifetime juga sudah tidak dipakai; harga sekarang dua paket: Standard Rp 599.000/tahun dan Organisasi Rp 5.999.000/tahun (lewat kontak manual).

1

Web hidup di hosting

± 30 menit · gratis, belum pakai domain
Siap dikerjakan

Memastikan hostingnya jalan dulu sebelum menyentuh apa pun yang lain.

  1. Buat akun GitHub dan Cloudflare.
  2. Jadikan folder LetsMap repo Git, git push ke GitHub (aman dibuat publik — hanya anon key Supabase yang ikut, dirancang untuk sisi peramban).
  3. Cloudflare → Workers & Pages → Create → Pages → Connect to Git, pilih repo.
  4. Build command dikosongkan, build output / — situs ini tanpa build step.
  5. Save and Deploy.
Cek: buka https://<nama-proyek>.pages.dev di HP. Landing page tampil, bisa "Add to Home screen". Login belum jalan — itu normal, masih mode tamu.
2

Database & jatah uji coba

± 20 menit · supabase-schema.sql sudah siap
File siap, tinggal jalankan

Jatah uji coba (2 misi, 1 proyek olah data) dihitung di server lewat tabel ini — bukan di peramban, jadi tidak bisa direset dengan hapus data.

  1. Buat proyek di supabase.com, region Southeast Asia (Singapore).
  2. SQL Editor → New query, tempel seluruh isi supabase-schema.sql, jalankan.
Cek: di Table Editor, tabel profiles ada dengan kolom plan, missions_used, projects_used.
Catatan free tier: proyek yang tidak disentuh 7 hari akan dijeda — buka dashboard sekali seminggu selama masih sepi.
3

Login Google

± 30 menit · butuh halaman Privasi & Syarat lebih dulu
Terhalang

Alurnya: peramban → Google → Supabase → kembali ke situs. Yang didaftarkan ke Google adalah alamat Supabase, bukan alamat situs sendiri — ini yang paling sering tertukar.

  1. Google Cloud Console → proyek baru Ukurra.
  2. OAuth consent screen: User type External, nama app Ukurra, scope cukup email profile openid. Privacy Policy URL dan Terms of Service URL wajib diisi — lihat Tahap 7.
  3. Credentials → OAuth client ID, type Web application. Redirect URI satu baris saja: https://<ref-proyek>.supabase.co/auth/v1/callback.
  4. Supabase → Authentication → Providers → Google, aktifkan, tempel Client ID + Secret.
  5. Supabase → Authentication → URL Configuration: Site URL = https://<nama-proyek>.pages.dev; Redirect URLs tambahkan https://<nama-proyek>.pages.dev/** dan ukurra://auth (baris kedua ini dipakai aplikasi desktop — tanpa itu login Studio ditolak).
  6. Isi assets/js/config.js: SUPABASE_URL dan SUPABASE_ANON_KEY dari Supabase → Project Settings → API. Push.
Cek: login dengan Google di situsnya. Tabel profiles di Supabase harus muncul satu baris, plan = free, missions_used = 0. Ekspor satu misi → muat ulang → angkanya jadi 1.
Tanpa halaman Privasi/Syarat (Tahap 7), OAuth cuma bisa mode Testing — maksimal 100 akun yang harus didaftarkan manual satu-satu di Google Cloud Console. Tidak bisa dipakai publik.
4

Domain ukurra.com

± 20 menit · pengeluaran pertama, ± Rp 165.000/tahun
Belum dibeli
  1. Cloudflare → Domain Registration → Register Domain, cari ukurra.com (Cloudflare jual di harga modal).
  2. Workers & Pages → proyek → Custom domains, masukkan ukurra.com — DNS dan HTTPS terpasang sendiri kalau domainnya dibeli di Cloudflare.
  3. Supabase → URL Configuration: ubah Site URL ke https://ukurra.com, tambahkan https://ukurra.com/** ke Redirect URLs.
Cek: https://ukurra.com terbuka dengan kunci HTTPS, login Google masih jalan dari alamat baru.
5

Pembayaran

± 30 menit · Lynk.id atau Mayar.id
Belum dibuat

Hanya paket Standard yang butuh checkout swalayan. Paket Organisasi dijual lewat tombol "Hubungi Kami" (mailto:) yang sudah ada — tidak perlu produk pembayaran untuk itu.

  1. Buat akun di Lynk.id (paling cepat) atau Mayar.id (ada webhook, lebih cocok kalau sudah ramai).
  2. Buat dua produk terpisah — Standard Tahunan Rp 599.000 dan Standard Bulanan Rp 69.000. Lynk/Mayar tidak membaca parameter ?plan= yang dikirim situsnya, jadi memang harus dua produk, bukan satu produk dengan dua harga.
  3. Tempel tautan produk Tahunan (yang ditonjolkan) ke CHECKOUT_URL di config.js.

Aktivasi manual dulu: sampai webhook dibuat, jadikan akun Standard lewat SQL Editor setelah pembayaran masuk (perintahnya ada di bagian bawah supabase-schema.sql). Untuk puluhan pembeli pertama ini masih wajar.

Cek: klik "Mulai Berlangganan" di situs, sampai ke halaman Lynk/Mayar dengan harga yang benar.
5b

Sambungkan aplikasi desktop

Login & gerbang jatah sudah dibangun di kode
Tinggal isi config

Ukurra Studio memakai akun Google yang sama dengan web, supaya jatah uji coba tidak bisa diulang dengan berpindah aplikasi. Alur login (PKCE lewat peramban sistem + protokol ukurra://) dan gerbang jatah (1 proyek) sudah selesai dibangun — di LetsMapApp/auth.js, dipanggil dari main.js. Tinggal isi kredensial.

  1. Buka LetsMapApp/config.js, isi SUPABASE_URL, SUPABASE_ANON_KEY, CHECKOUT_URL — sama persis dengan nilai di web.
  2. Pastikan ukurra://auth sudah ada di Redirect URLs Supabase (Tahap 3).
  3. Bangun ulang installer-nya supaya config.js yang terisi ikut terpaket.
Cek: buka Ukurra Studio, klik "Masuk dengan Google", peramban terbuka lalu kembali ke aplikasi dengan nama akun tampil. Olah satu proyek sampai selesai → di Supabase, projects_used jadi 1. Coba olah lagi → ajakan berlangganan muncul.
6

Bagikan installer desktop

Cloudflare R2 · installer ± 600–800 MB
Belum di-hosting

Jauh di atas batas 25 MiB per berkas di Cloudflare Pages — installer tidak boleh ikut masuk repo web. R2: 10 GB gratis, dan yang menentukan, unduhan tidak ditagih.

  1. Cloudflare → R2 → Create bucket, nama ukurra-rilis.
  2. Unggah Ukurra-Studio-Setup.exe.
  3. Settings → Public access → Connect custom domain, pakai unduh.ukurra.com.

Tautannya jadi https://unduh.ukurra.com/Ukurra-Studio-Setup.exe — tombol "Unduh Ukurra Studio" di landing page sudah dipasang dan menunggu tautan ini hidup, tidak perlu sentuh kode lagi.

Unduhan sengaja tidak dikunci di balik pembayaran — batas 1 proyek gratis sudah ditegakkan di dalam aplikasi sendiri (Tahap 5b), jadi mengunci tautan unduhan hanya menyusahkan pengguna sah.

Cek: klik tombol "Unduh Ukurra Studio" di landing page, installer terunduh.
7

Halaman Privasi & Syarat Penggunaan

Wajib untuk OAuth Google keluar dari mode Testing
Belum ada

privacy.html dan terms.html belum ada di proyek ini. Tanpa dua halaman ini terpasang di OAuth consent screen (Tahap 3), Google membatasi login ke mode Testing — maksimal 100 akun, didaftarkan manual satu-satu. Produk tidak bisa dipakai publik tanpa ini.

  1. Tulis privacy.html — data apa yang dikumpulkan (email dari Google, data misi/proyek), untuk apa, disimpan di mana (Supabase), cara pengguna minta dihapus.
  2. Tulis terms.html — syarat pakai, batasan tanggung jawab, kebijakan uji coba & langganan.
  3. Pasang keduanya di repo, deploy, lalu tempel URL-nya ke OAuth consent screen di Google Cloud Console.
  4. Ajukan verifikasi/publish app di Google Cloud Console supaya keluar dari mode Testing.
Cek: OAuth consent screen berstatus "In production", bukan "Testing". Akun Google mana pun bisa login tanpa didaftarkan manual lebih dulu.

Boleh dikerjakan belakangan, tidak menghalangi peluncuran teknis

Tinjauan hukum soal lisensi AGPL OpenDroneMap (ODM dipanggil sebagai program terpisah, tidak dimodifikasi — polanya sudah dirancang untuk ini) sebaiknya selesai sebelum rupiah pertama masuk, tapi tidak menghalangi tahap 1–7 di atas berjalan. Kerjakan paralel, bukan sebagai gerbang.

Setelah tahap 1–7 selesai

Siapa pun bisa buka ukurra.com, login dengan Google, pakai mission planner dengan jatah 2 misi gratis, unduh Ukurra Studio dan olah 1 proyek gratis, lalu berlangganan Standard lewat Lynk/Mayar kalau jatahnya habis — semua tanpa campur tangan manual, kecuali mengaktifkan status Standard lewat SQL Editor sampai webhook dibangun.
